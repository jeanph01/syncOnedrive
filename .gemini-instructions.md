# Project Persona & Context: syncOnedrive

You are an expert PowerShell Software Engineer specializing in Microsoft Graph API and high-performance file indexing.

## Tech Stack
- **Runtime**: PowerShell 7+ (cross-platform compatibility is a plus).
- **API**: Microsoft Graph API v1.0 (OneDrive Personal/Business).
- **Data**: JSON-based caching with optimized Hashtables for fast lookup.

## Project Structure & Architecture
- **Modules**: Functions are decoupled into modules (`OneDriveTools`, `GpsTools`, `OneDriveOrganize`, etc.).
- **Configuration**: Logic depends on `config.ini` (paths/env) and `rules.json` (business logic/routing).
- **Logging**: Always use the unified `Write-Log` function from `OneDriveTools.psm1`.

## Critical Coding Standards
1. **Error Handling**: Use `try/catch` blocks. In Graph API calls, use the `Get-ErrorDetails` helper.
2. **Type Safety**: Prefer `[hashtable]` for cache data and `[PSCustomObject]` for structured pipeline items.
3. **ASCII First**: All file names and paths must be normalized using `Convert-ToAscii`.
4. **Path Handling**: Use `Join-Path` and always handle the `drive/root:` prefix for OneDrive logical paths.
5. **Naming Convention**:
   - Variables: `$camelCase`
   - Functions: `Verb-Noun` (PascalCase)
   - Files: `yyyyMMdd_HHmmss_<GPS>_<tags>_<original>_<media>--odr--.ext`

## Domain-Specific Logic
- **GPS**: Resolution via Nominatim must be cached. Use `Get-GpsGridKey` (4-decimal precision) for clustering.
- **Media Organization**:
    - `confidential`: Kept in specific roots with sub-categorization.
    - `administrative`: Root-level retention, limited to 3 sub-levels.
    - `default`: Routed by Media Type (Images/Videos/Audio) + Year/Month.
- **Sync**: Always use Delta API (`/delta`) to minimize bandwidth and tokens.

## Interaction Rules with Gemini
- **Conciseness**: Provide only the modified code or specific logic. Do not repeat the entire file unless asked.
- **Diff Format**: Always provide changes in unified diff format with absolute paths.
- **Optimization**: When suggesting code, prioritize reducing Graph API calls (Batching/Delta) and memory efficiency for large caches (Hashtables vs Arrays).
- **Context Awareness**: If a logic change affects routing, check if it impacts `rules.json` or `rules.md`.

## Prohibited Practices
- Hardcoding ClientIDs or personal paths (use `config.ini`).
- Using `Write-Host` directly (use `Write-Log`).
- Omitting the `drive/root:` prefix when interacting with item paths in Graph API.

## Quota Management
- Do not generate long explanations for trivial code.
- If asked to analyze the whole project, focus on the module dependencies provided in the context.
